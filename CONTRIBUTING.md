# Contributing

See the wiki's [Contributing](https://github.com/metalayerlab/mitm-proxy/wiki/Contributing) page (source: `docs/wiki/Contributing.md`).
In short:

- Branch `feat/<topic>`, open a PR against `main`, and give it a Conventional Commit title (`feat: ...`,
  `fix: ...`). It is squash-merged, and the title becomes the CHANGELOG line.
- Code, tests and `docs/wiki/` change together. AGENTS.md's "Docs map" says which page goes with which code.
- Don't edit `CHANGELOG.md` or the version: release-please does that.
- Working with an AI assistant? Read [AGENTS.md](AGENTS.md) and [docs/ai/](docs/ai/).
